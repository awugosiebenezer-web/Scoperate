# ScopeRate

A free, privacy-first freelance project pricing and scope calculator. ScopeRate turns itemized work, uncertainty, direct costs, platform fees, profit, and a planning tax reserve into a fixed quote and printable client estimate.

## Why this business

Research in August 2026 showed a durable freelancer pain point: calculating a rate is crowded, but community discussions repeatedly emphasize the harder workflow around fixed-price estimation—itemized scope, unknowns, revision limits, deposits, and change orders. ScopeRate differentiates by joining calculation and a client-ready scope document, entirely in-browser.

## Zero-cost stack

Static HTML, CSS, and JavaScript; no database or paid API. Designed for GitHub source control and Vercel's free tier.

## Run and test

```bash
npx serve . -l 3000
npm test
```
